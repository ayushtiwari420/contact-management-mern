# 📇 ContactHub – MERN Contact Management App

ContactHub is a full-stack **MERN (MongoDB, Express, React, Node.js)** application that allows users to securely manage their personal contacts.  
Each user can register, log in, and perform full CRUD operations on their own contacts.

---

## 🚀 Features

- 🔐 User Authentication (JWT-based)
- 👤 Secure User Registration & Login
- 📞 Create, Read, Delete Contacts
- 🔍 Real-time Search (Name / Phone)
- 📄 Pagination for Scalable Data Handling
- 🎨 Modern Responsive UI (Tailwind CSS)
- 🔒 User-specific Data Isolation
- 🗄 MongoDB Persistence

---

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
